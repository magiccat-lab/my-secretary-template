# 機能提案 — AI 秘書の使い道カタログ

このファイルは「秘書として 何ができるか / 何を増やすと刺さるか」 のアイデア集です。
README が「いま入ってる機能」 を書くのに対し、 このファイルは
「将来こう使える / こう拡張できる」 を、 利用者属性 と 心理ニーズ から並べます。

Phase 1 / Phase 2 の実機能と区別するため、 ここに書かれているものは
**提案ステータス** であり、 実装済とは限りません。

---

## 1. 入口になる 3 つの定番

最初に検討されがちな 3 つです。

- **予定管理 / リマインド** — 期日・予定・繰り返しの忘却を防ぐ。 入口として強い。
- **レコメンド** — 食事 / 旅行 / 書籍 / 映像など、 好みベースの推薦。
- **小さな仕組み化** — 「家計集計」「定期チェック」「メール返信雛形」 のような、
  自分用の単発タスクを軽く自動化する。 元は 「開発」 と呼ばれがちですが、
  友達層に届ける言葉は 「面倒を自分用に自動化する代理人」 が近い。

---

## 2. 機能ではなく 心理ニーズ から見ると

「記録したい」「処理したい」 とユーザーは思っていないことが多いです。
実態は 心理 が先にあって、 機能が後から来ます。

| ユーザー心理 | 機能カテゴリ | 例 |
|---|---|---|
| 忘れても大丈夫にしたい | 記録 + 想起 | 予定 / 日記 / 健康ログ / 家計 / 趣味の log |
| 返事に詰まりたくない | 受信処理 + 下書き | メール / DM の filter、 重要通知の要約、 返信雛形 |
| 自分の代わりに目を通してほしい | リサーチ + 要約 | ニュース / PDF / 動画 / SNS の差分通知 |
| 何かを 「やってほしい」 | 行動代行 | レストラン / 美容室予約、 連絡代行、 買い物リスト化 |
| 寄り添ってほしい | 会話 / 壁打ち | 思考整理、 アイデア出し、 SNS 投稿草稿、 文章添削 |
| 大切な人を見守りたい | 見守り / 介護補助 | 服薬 / 通院リマインド、 家族予定共有 |
| 自分を育てたい | 学習 / 振り返り | 読書 ログ、 暗記 quiz、 月次振り返り、 目標トラッキング |

このマッピングで提案すると、 利用者は 「機能リスト」 ではなく
「自分の悩み」 から入れるため、 続けやすくなります。

---

## 3. 属性別 — 見落としやすい使い道

利用者の属性を変えると、 同じ AI 秘書でも 効くポイントが変わります。

- **学生** — 課題 / 締切 / 授業資料 / 就活メール / 面接練習を横断管理。
- **営業** — 商談メモから 次 action 抽出、 返信文生成、 顧客別の温度感記録。
- **マーケッター** — 競合観察、 SNS / ニュースの要約、 施策アイデアの壁打ち。
- **主婦 / 家庭運営** — 学校プリント、 家族予定、 買い物、 献立、 通院、 役所手続き。
- **高齢者** — 薬 / 通院 / 家族連絡 / 詐欺メール相談 / 日々の見守り。
- **クリエイター** — 制作タスク管理、 構想メモ、 リサーチ、 SNS 投稿草稿、 反応集計。
- **小規模事業者** — 顧客連絡、 請求書ドラフト、 SNS 運用、 簡易日報。

特に **ライフイベント期** [転職 / 引越し / 出産 / 介護 等] は
タスクが多く 期限が分散するため、 AI 秘書との相性が良いタイミングです。

---

## 4. AI 秘書だからこそ できること

人間秘書 や 既存アプリ で 代替しにくいものをまとめます。

1. **複数チャネル横断の記憶** — Gmail / Calendar / Discord / Notion をまたいで
   「前に言っていた件」 を扱える。 アプリの境界を意識しなくて良い。
2. **低摩擦な自然言語運用** — フォームを開かずに 「これ覚えて」「明日聞いて」 で済む。
3. **曖昧な情報の構造化** — メモ / メール / 会話から、 期限 / 相手 / 次 action を推定。
4. **個人文脈込みのレコメンド** — 一般的おすすめではなく、 その人の予定 / 好み /
   過去ログ / 生活制約 に合わせる。
5. **24時間の軽い伴走** — 人間秘書ほど重くなく、 既存アプリほど受け身でもない。

---

## 5. Killer Use Case 候補

ひとつだけ最有力を選ぶなら:

### 生活 inbox 秘書

> 受信情報 [Mail / 通知 / 依頼 / 書類] から、 次 action を自動で拾い、
> リマインド + 下書き + 予定化 までを一通りやってくれる秘書。

採用理由:

- 友達層の多くが、 毎日 mail / DM / 予定 / 書類 / 依頼 / 締切に追われている。
- **新しい習慣を強制せず**、 既存の Gmail / Calendar / Notion / Discord に乗る。
- 「忘れない」「返信に困らない」「あとで探せる」 は 職業 / 年齢問わず刺さる。
- レコメンドや学習より **継続頻度が高く**、 開発より **対象者が広い**。

Phase 2 で入れた `gmail_monitor` + `nightly_handoff` + `chat_search` の組み合わせは、
この方向性に近い基礎です。

## 6. 既存実装との対応

提案を実装に落としたい場合の、 現状ファイル / 機能との対応です。

| 提案カテゴリ | 既に Phase 1 / 2 にあるもの | 不足しているもの |
|---|---|---|
| 予定管理 / リマインド | `scripts/integrations/gcal/gcal_remind.py`、 タスクリマインダー | スマホ通知の往復、 完了マーク連動 |
| レコメンド | `scripts/recommendations/sample_scrape_recommend.py` | 個人文脈反映、 ジャンル横断 |
| 小さな仕組み化 | `templates/onboarded/` 6 sample | UI なしのフロー組み立て補助 |
| 受信情報処理 | `integrations/gmail/gmail_monitor.py` + filter_rules.yaml | 下書き生成、 既読/未対応の分離 |
| 会話 / 壁打ち | 既存の Discord 会話 | 長期文脈の構造化想起 |
| 行動代行 | webhook 系 | 外部 API 連携の追加 |
| 見守り / 介護補助 | cron + Discord 通知 | 家族共有 channel、 確認応答ループ |
| 学習 / 自己成長 | `scripts/trainer/` 系 | 振り返り対話、 quiz 生成 |
